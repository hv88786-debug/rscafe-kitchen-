# RS Cafe & Kitchen — Mobile Menu

A premium mobile-first digital menu and ordering experience for **RS Cafe & Kitchen**, Panchsheel Nagar, Ajmer, Rajasthan.

## Features

- 🍕 Interactive food menu with categories (Pizza, North Indian, Burgers, Chinese, Pastas, Sandwiches, Beverages, Desserts)
- 🔍 Live search and dietary filters (Veg / Non-Veg / Chef's Choice)
- 🛒 Cart with quantity controls, bill summary, and GST calculation
- 📱 WhatsApp order integration
- ⭐ Customer reviews section
- 📸 Instagram feed showcase
- 📍 Location, hours & contact info
- 🎨 Royal Rajputana design system with Playfair Display & Plus Jakarta Sans typography

## Tech Stack

- Pure HTML, CSS (Tailwind CSS via CDN), and vanilla JavaScript
- No build step required — static site
- Optimized for mobile-first responsive design

## Deployment

This project is deployed on [Vercel](https://vercel.com). Simply connect the GitHub repository and Vercel will serve `index.html` automatically.

## Local Preview

Open `index.html` in any browser.
